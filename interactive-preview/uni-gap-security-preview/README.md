# Uni-Gap Security — Interactive Preview

This is a standalone, dependency-free browser preview of the Uni-Gap Security frontend.

## Open

Double-click `index.html` or open it in Chrome/Edge/Firefox.

No Node.js, npm install, server, backend, database, or ML service is required for this preview.

## Included interactive areas

- Login/logout
- 14 application pages
- Light/dark theme
- Global command palette with Ctrl/Cmd+K
- Notifications
- Analyst profile menu
- Live mock alerts
- Pause/resume monitoring
- Threat search/filtering
- Alert investigation drawer
- Alert JSON viewer
- Save observation / audit events
- Evidence explorer
- PCAP replay demo controls
- Incident actions
- Threat-hunt search
- Analytics time ranges
- Report preview
- CSV/JSON/Excel-compatible browser exports
- Audit search/export
- Settings and database connection simulation
- One-way data-diode visualization

This preview is a UI demonstration. The production Next.js frontend ZIP remains the source of truth for the real application.
